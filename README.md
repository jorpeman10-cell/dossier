# ✦dossier — 可证伪的简历 Harness

> 简历不该是一份形容词清单，而该是一条证据链。

**✦dossier** 是一个开源的 Claude Code Agent Harness：通过访谈帮你生成
「词条式」个人档案页。与所有简历工具的区别在于：它不只帮你写，
还帮你**被验证**。

## 核心特性

- **访谈式生成**：Agent 按 8 问脚本访谈你，产出「自我叙事 / 一天的工作 /
  观点 / 著录 / 田野日志 / 双栏工具栏」六段式档案，中英双语一键切换
- **自动证伪**：每条经历的可证据链接由 Agent 实际抓取核验，按三级标记：
  - `✓` 专家核验（人工访谈背书）
  - `◐` 作品可查（Agent 已抓取确认链接有效、内容相符）
  - `○` 本人自述（如实标注，不装点）
- **合规红线内置**：患者数据 / 人类遗传资源 / 现雇主机密流程一律拒收，
  敏感信息自动落 NDA 层，页面只出脱敏版
- **工作流资产登记**：附 PAWAS 元数据规范，你的工作流可登记为
  可复现、可 fork 的资产，并链接进简历的「著录」区

## 快速开始

**在线示例**：创始人 Steven 的范式简历（终端范式，多源证据版）——
[https://jorpeman10-cell.github.io/dossier/steven/](https://jorpeman10-cell.github.io/dossier/steven/)

```bash
# 1. 用本仓库作为模板建你自己的仓库，克隆到本地
# 2. 在仓库目录里启动 Claude Code
claude
# 3. 对它说：
#    "帮我做简历档案"
# 访谈约 40 分钟，产出 me/index.html
# 4. 推到 GitHub，Settings → Pages 开启，得到你的档案页
```
